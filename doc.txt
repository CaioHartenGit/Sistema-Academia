O padrão que está aparecendo

Você já percebeu que está ficando assim:

inserir()
→ Repository devolve 1 tupla
→ Service cria 1 Aluno
listar()
→ Repository devolve várias tuplas
→ Service usa for
→ cria vários Aluno
buscar_por_id()
→ Repository devolve 1 tupla
→ Service cria 1 Aluno
atualizar()
→ Repository devolve 1 tupla
→ Service cria 1 Aluno

Main       → conversa com o usuário
Service    → decide como a operação deve acontecer
Repository → conversa com o banco
Conexão    → conecta ao banco
Aluno      → representa e valida os próprios dados
